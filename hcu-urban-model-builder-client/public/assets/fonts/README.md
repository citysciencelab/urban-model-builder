# Fonts

Self-hosted typefaces of the UMB Design System (latin subset, woff2), taken
from the Fontsource packages `@fontsource/funnel-display`,
`@fontsource/funnel-sans` and `@fontsource/ibm-plex-mono` (5.3.0).

| Family         | Weights  | Use                         | Licence     |
| -------------- | -------- | --------------------------- | ----------- |
| Funnel Display | 700, 800 | Titles                      | SIL OFL 1.1 |
| Funnel Sans    | 400, 600 | Interface text              | SIL OFL 1.1 |
| IBM Plex Mono  | 400, 500 | Plan labels, meta and values | SIL OFL 1.1 |

Licence text: https://openfontlicense.org/open-font-license-official-text/

The `@font-face` rules live in `app/styles/design-system/_fonts.scss`.
